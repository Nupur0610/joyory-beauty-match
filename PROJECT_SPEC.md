# Joyory Beauty Match

## Problem

Beauty shoppers face too many products and struggle to identify what suits their individual needs, compare products, understand ingredients, and build a complete routine.

## Solution

Joyory Beauty Match is a personalized beauty shopping assistant.

It asks customers a few questions about their needs and recommends suitable products.

## User Journey

Home
→ Quiz
→ Personalized Recommendations
→ Product Comparison
→ Routine
→ Cart
→ Checkout
